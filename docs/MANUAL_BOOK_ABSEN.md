# KATA PENGANTAR

Buku Panduan Pengguna ini disusun sebagai acuan bagi seluruh perangkat Desa Karang Bongkot dalam menggunakan Aplikasi ABSEN. Aplikasi ini digunakan melalui telepon genggam untuk melakukan absen masuk dan pulang dengan foto wajah dan lokasi GPS, melihat riwayat kehadiran, serta mengajukan izin dan koreksi absen.

Buku ini disusun berurutan mulai dari pengenalan aplikasi, cara masuk, hingga langkah-langkah rinci setiap menu. Setiap bab dilengkapi tujuan, langkah kerja, hasil yang diharapkan, serta penanganan apabila terjadi kendala.

Panduan untuk Aplikasi ADMIN yang digunakan untuk memantau absensi dan meninjau pengajuan disusun dalam buku terpisah.

Semoga buku panduan ini membantu tertib kehadiran perangkat Desa Karang Bongkot.

# BAB I PENDAHULUAN

## 1.1 Latar Belakang

Pencatatan kehadiran perangkat desa perlu dilakukan secara tertib, jujur, dan dapat ditelusuri. Aplikasi ABSEN memastikan absen dilakukan oleh pegawai yang bersangkutan (melalui pencocokan wajah), di lokasi kantor (melalui GPS), dan pada waktu yang tercatat oleh server, sehingga data kehadiran dapat dipertanggungjawabkan.

## 1.2 Tujuan Buku Panduan

1. Memberikan petunjuk langkah demi langkah dalam menggunakan setiap menu Aplikasi ABSEN.
2. Menjelaskan aturan absen masuk, absen pulang, izin, dan koreksi absen.
3. Menjadi rujukan ketika pengguna mengalami kendala.

## 1.3 Ruang Lingkup

Buku ini hanya membahas Aplikasi ABSEN yang dibuka melalui telepon genggam oleh pegawai. Pemantauan absensi, peninjauan (persetujuan/penolakan) izin, pendaftaran wajah, dan pengaturan jadwal dilakukan oleh Admin melalui Aplikasi ADMIN dan dibahas dalam buku panduan tersendiri.

## 1.4 Gambaran Umum Aplikasi

Aplikasi ABSEN memiliki empat menu utama yang tampil di bagian bawah layar:

| Menu | Fungsi |
|---|---|
| **Beranda** | Jam dan tanggal, jadwal hari ini, status absen, tombol absen masuk/pulang |
| **Riwayat** | Catatan absen per bulan beserta foto selfie |
| **Izin** | Pengajuan izin dan koreksi absen beserta statusnya |
| **Profile** | Data akun, pengaturan tema tampilan, dan keluar |

[[GAMBAR SS-01-01 | Menu bawah aplikasi | Tangkapan layar Beranda di HP dengan bilah menu bawah terlihat jelas: Beranda (aktif), Riwayat, Izin, dan Profile. Beri tanda/nomor pada setiap menu.]]

## 1.5 Kebutuhan Sistem

1. Telepon genggam dengan **kamera depan** dan **GPS** yang berfungsi.
2. Peramban (browser) **Google Chrome** versi terbaru.
3. Koneksi internet (data seluler atau Wi-Fi).
4. Alamat web Aplikasi ABSEN yang diberikan oleh Admin.
5. **Akun** (username dan kata sandi) yang telah dibuatkan Admin.
6. **Foto wajah sudah didaftarkan** oleh Admin. Tanpa pendaftaran wajah, pegawai tidak dapat melakukan absen.
7. **Jadwal kerja** sudah diatur oleh Admin.

## 1.6 Konvensi Penulisan

| Penulisan | Arti |
|---|---|
| **Tebal** | Nama tombol, menu, atau tab persis seperti yang tertulis di layar |
| Menu › Bagian | Urutan menu yang dibuka |
| Tanda bintang (*) | Isian wajib diisi |
| Ketuk | Menyentuh tombol atau menu di layar HP |
| Kotak Gambar | Posisi tangkapan layar (screenshot) |

## 1.7 Ketentuan Waktu

Semua jam yang tampil dan tercatat di aplikasi menggunakan **jam server dalam Waktu Indonesia Tengah (WITA)**, bukan jam pada HP. Mengubah jam HP tidak memengaruhi waktu absen.

1. Buka **Google Chrome** di HP.
2. Ketik alamat Aplikasi ABSEN yang diberikan Admin, lalu buka.
3. Halaman login akan tampil.

## 2.2 Menambahkan Pintasan ke Layar Utama HP

Agar aplikasi dapat dibuka seperti aplikasi biasa, buat pintasan di layar utama HP:

1. Buka Aplikasi ABSEN di Chrome.
2. Ketuk ikon **⋮** (titik tiga) di pojok kanan atas Chrome.
3. Pilih **Tambahkan ke layar utama** (*Add to Home screen*).
4. Ketuk **Tambahkan**.
5. Ikon aplikasi muncul di layar utama HP. Selanjutnya cukup ketuk ikon tersebut.

## 2.3 Masuk ke Aplikasi (Login)

**Tujuan:** masuk ke Aplikasi ABSEN menggunakan akun masing-masing.

1. Pada halaman **Masuk ke akun**, isi kolom **Username**.
2. Isi kolom **Kata sandi**. Ketuk ikon mata untuk menampilkan atau menyembunyikan kata sandi.
3. Ketuk tombol **Masuk**.
4. Apabila berhasil, muncul notifikasi **Selamat datang, {nama}** dan aplikasi membuka **Beranda**.

Setelah berhasil masuk, aplikasi mengingat akun Anda sehingga tidak perlu login setiap kali dibuka, sampai Anda keluar atau sesi berakhir.

**Apabila gagal:**

| Pesan | Penyebab dan Penanganan |
|---|---|
| Username atau kredensial salah | Username atau kata sandi keliru. Periksa penulisan, termasuk huruf besar/kecil. |
| Akses ditolak / akun tidak aktif | Akun dinonaktifkan atau bukan akun pegawai. Hubungi Admin. |
| Tidak dapat terhubung ke server | Periksa koneksi internet, lalu ulangi. |

[[GAMBAR SS-02-04 | Pesan login gagal | Tangkapan layar halaman login dengan pesan merah "Username atau kredensial salah" di atas kolom Username.]]

## 2.4 Lupa Kata Sandi (Kode Pemulihan)

1. Hubungi Admin atau operator Kantor Desa dan minta **kode pemulihan** akun Anda (6 karakter).
2. Pada halaman login, isi **Username** seperti biasa.
3. Isi kolom **Kata sandi** dengan kode pemulihan dari Admin.
4. Ketuk **Masuk**.

Penggantian kata sandi dilakukan oleh Admin. Aplikasi ABSEN belum menyediakan menu ganti kata sandi sendiri.

## 2.5 Keluar dari Aplikasi (Logout)

1. Ketuk **avatar** (lingkaran berisi inisial nama) di pojok kiri atas Beranda, lalu pilih **Keluar**; atau buka menu **Profile** lalu ketuk **Keluar**.
2. Muncul notifikasi **Keluar dari akun?**.
3. Ketuk **Ya, keluar** untuk keluar, atau **Tidak** untuk membatalkan.
4. Aplikasi kembali ke halaman login.

# BAB IV ABSEN MASUK DAN PULANG

## 4.1 Aturan Absen

| Ketentuan | Absen Masuk | Absen Pulang |
|---|---|---|
| Dibuka | **60 menit sebelum jam masuk** | Setelah absen masuk; atau tanpa absen masuk apabila **jam pulang sudah lewat** (lupa absen masuk) |
| Ditutup | **Pada jam pulang** | Akhir hari (pukul 24.00) |
| Status | Lewat jam masuk + toleransi → **Terlambat** | Sebelum jam pulang → **Pulang cepat** |
| Jumlah | 1 kali per hari | 1 kali per hari |

Syarat setiap absen:

1. **Hari kerja** sesuai jadwal dan bukan hari libur desa.
2. **Lokasi** berada di dalam radius salah satu **lokasi kantor aktif** (yang terdekat dipakai).
3. **Akurasi GPS** paling besar **50 meter**.
4. **Foto wajah** berisi tepat satu wajah dan **cocok** dengan wajah yang didaftarkan Admin.

Jam buka, batas akurasi GPS, radius kantor, dan toleransi terlambat ditetapkan oleh Admin dan dapat berubah.

## 4.2 Langkah Absen Masuk

**Tujuan:** mencatat kehadiran saat tiba di kantor.

1. Pada **Beranda**, ketuk **Absen Masuk**.
2. Saat pertama kali, browser meminta izin. Ketuk **Izinkan** untuk **kamera** dan **lokasi**.
3. Layar **Absen Masuk** terbuka: kamera depan menyala dengan **bingkai oval**, dan di bawahnya kotak status lokasi.
4. Tunggu hingga kotak status berwarna **hijau** bertuliskan **Lokasi siap (±xx m)**.
   - Kotak **kuning** "Mencari lokasi…" atau "Menunggu GPS lebih akurat (±xx m, maks 50 m)": tombol kirim belum dapat ditekan. Tunggu atau pindah ke tempat terbuka.
5. Posisikan wajah di dalam bingkai oval. Pastikan wajah terlihat jelas, cahaya cukup, dan tidak ada orang lain di foto.
6. Ketuk **Ambil foto & kirim**. Tombol berubah menjadi **Mengirim…**.
7. Apabila berhasil, muncul notifikasi **Absen Masuk tercatat** (ditambah keterangan terlambat bila ada) dan aplikasi kembali ke Beranda.

[[GAMBAR SS-04-02 | Layar absen siap | Tangkapan layar layar Absen Masuk: tombol kembali dan judul di atas, kamera depan dengan bingkai oval putus-putus berisi wajah, kotak hijau "Lokasi siap (±10 m)", dan tombol "Ambil foto & kirim".]]

[[GAMBAR SS-04-03 | Menunggu GPS | Tangkapan layar layar absen dengan kotak kuning "Menunggu GPS lebih akurat (±80 m, maks 50 m)" dan tombol kirim berwarna pudar (nonaktif).]]

[[GAMBAR SS-04-04 | Absen berhasil | Tangkapan layar Beranda dengan notifikasi hijau "Absen Masuk tercatat" di atas, dan jam masuk terisi.]]

## 4.3 Langkah Absen Pulang

1. Pada **Beranda**, ketuk **Absen Pulang**.
2. Apabila belum jam pulang, muncul notifikasi **Belum jam pulang. Tetap absen pulang?**
   - Ketuk **Ya, pulang** untuk melanjutkan (status akan tercatat **Pulang cepat**), atau **Batal**.
3. Ikuti langkah 3–7 pada Subbab 4.2.
4. Apabila berhasil, Beranda menampilkan **Presensi hari ini lengkap**.

[[GAMBAR SS-04-05 | Konfirmasi pulang cepat | Tangkapan layar notifikasi "Belum jam pulang. Tetap absen pulang?" dengan tombol "Ya, pulang" dan "Batal".]]

## 4.4 Lupa Absen Masuk

Apabila lupa absen masuk dan jam pulang sudah lewat, Beranda langsung menampilkan tombol **Absen Pulang** sehingga absen pulang tetap dapat dilakukan. Untuk absen masuk yang terlewat, ajukan **koreksi absen** (Subbab 6.4).

## 4.5 Sudah Absen Masuk lalu Mengajukan Izin

Apabila sudah absen masuk lalu mengajukan izin untuk hari yang sama (misalnya pulang karena sakit), tombol **Absen Pulang** tetap tersedia di Beranda.

## 4.6 Apabila Absen Gagal

Pesan kegagalan muncul sebagai notifikasi merah dan layar absen tetap terbuka sehingga dapat langsung mencoba lagi. Setiap kegagalan tercatat otomatis dan dapat dilihat Admin.

| Pesan | Penyebab dan Penanganan |
|---|---|
| Izin lokasi ditolak / Izin kamera ditolak | Izin browser ditolak. Aktifkan di pengaturan Chrome (ikon gembok di kolom alamat › Izin), lalu ketuk **Coba lagi**. |
| Lokasi tidak tersedia. Pastikan GPS menyala | GPS HP mati. Nyalakan GPS, lalu ketuk **Coba lagi**. |
| GPS terlalu lama merespons | Sinyal GPS lemah. Pindah ke tempat terbuka, lalu ketuk **Coba lagi**. |
| Kamera tidak ditemukan / tidak dapat dibuka | Kamera dipakai aplikasi lain atau rusak. Tutup aplikasi lain, lalu **Coba lagi**. |
| Akurasi GPS kurang baik (maks 50 m) | GPS belum akurat. Tunggu beberapa detik di tempat terbuka. |
| Koordinat GPS tidak valid | Data lokasi dari HP tidak wajar. Matikan lalu nyalakan GPS, ulangi. |
| Di luar area {nama kantor} (jarak, maks radius) | Posisi di luar radius kantor. Mendekat ke kantor. Apabila sudah di kantor, tunggu GPS lebih akurat lalu ulangi. |
| Wajah tidak terdeteksi | Tidak ada wajah, wajah lebih dari satu, gelap, atau buram. Perbaiki posisi dan pencahayaan. |
| Wajah tidak cocok | Wajah tidak sesuai data. Ulangi dengan wajah menghadap kamera. Apabila terus gagal, hubungi Admin. Foto yang gagal disimpan untuk diperiksa Admin. |
| Foto wajah belum didaftarkan, hubungi admin | Hubungi Admin untuk pendaftaran wajah. |
| Absen masuk dibuka pukul HH.MM | Belum waktunya absen masuk. |
| Absen masuk ditutup pukul HH.MM, ajukan koreksi absen | Jam pulang sudah lewat. Ajukan koreksi absen (Subbab 6.4). |
| Belum absen masuk | Absen pulang sebelum jam pulang tanpa absen masuk. Lakukan absen masuk dahulu. |
| Sudah absen masuk/pulang hari ini | Absen tersebut sudah tercatat. Kembali ke Beranda. |
| Hari ini libur / Hari ini bukan hari kerja | Tidak perlu absen. |
| Pegawai belum punya jadwal kerja | Hubungi Admin. |
| Tidak dapat terhubung ke server | Periksa koneksi internet, lalu ulangi. |

[[GAMBAR SS-04-06 | Contoh absen gagal | Tangkapan layar layar absen dengan notifikasi merah "Di luar area Kantor Desa (250 m, maks 100 m)" di bagian atas.]]

# BAB V RIWAYAT ABSEN

## 5.1 Melihat Riwayat

**Tujuan:** melihat catatan absen sendiri per bulan.

1. Ketuk menu **Riwayat**.
2. Riwayat bulan berjalan tampil, terbaru di atas.
3. Ketuk **‹** untuk bulan sebelumnya, **›** untuk bulan berikutnya. Bulan setelah bulan berjalan tidak dapat dibuka.

Bagian halaman Riwayat:

1. **Pemilih bulan**.
2. **Ringkasan bulan**:
   - **Hadir**: jumlah hari dengan absen masuk atau pulang;
   - **Terlambat**: jumlah hari dengan absen masuk terlambat;
   - **Pulang cepat**: jumlah hari dengan absen pulang lebih awal.
3. **Kartu per hari**: tanggal, jam masuk dan pulang beserta label status. Tanda **--.--** berarti absen tersebut tidak tercatat.

Apabila bulan yang dipilih belum memiliki catatan, tampil keterangan **Belum ada presensi**.

[[GAMBAR SS-05-01 | Halaman Riwayat | Tangkapan layar halaman Riwayat dengan nomor penanda: (1) pemilih bulan "November 2026" dengan tombol ‹ ›; (2) tiga ubin ringkasan Hadir, Terlambat, Pulang cepat; (3) daftar kartu per hari.]]

## 5.2 Melihat Foto Absen

1. Pada kartu hari, ketuk jam **Masuk** atau **Pulang**.
2. Foto selfie saat absen tampil beserta keterangan jenis dan jamnya.
3. Ketuk **X**, ketuk area gelap di luar foto, atau tekan tombol kembali untuk menutup.

[[GAMBAR SS-05-02 | Foto absen | Tangkapan layar jendela foto selfie di atas latar gelap dengan keterangan "Masuk · 07.25" dan tombol X.]]

## 5.3 Label Koreksi

Kartu hari berlabel **Koreksi** berarti absen pada hari tersebut dicatat atau diubah oleh Admin, misalnya hasil pengajuan koreksi absen yang disetujui (Subbab 6.4). Absen hasil koreksi **tidak memiliki foto**, sehingga jamnya tidak dapat diketuk.

Absen hasil koreksi pada hari libur atau hari tanpa jadwal tetap dihitung **Hadir** dengan status **Tepat waktu**.

[[GAMBAR SS-05-03 | Hari berlabel Koreksi | Tangkapan layar kartu hari dengan label biru "Koreksi" di kanan atas dan jam masuk hasil koreksi.]]

# BAB VI PENGAJUAN IZIN DAN KOREKSI ABSEN

## 6.1 Jenis Pengajuan

| Jenis | Digunakan untuk |
|---|---|
| **Izin** | Tidak masuk kerja pada satu atau beberapa hari, misalnya sakit, keperluan pribadi, cuti, dinas luar, atau tugas lapangan |
| **Koreksi absen** | Absen masuk atau pulang yang terlewat atau gagal tercatat, misalnya lupa absen, HP mati, atau gangguan sinyal |

Semua pengajuan ditinjau (disetujui atau ditolak) oleh pejabat yang berwenang melalui Aplikasi ADMIN.

## 6.2 Daftar Pengajuan

1. Ketuk menu **Izin**.
2. Daftar pengajuan tampil, terbaru di atas. Setiap baris menampilkan jenis, tanggal, dan status.
3. Gunakan filter **Semua**, **Menunggu**, **Disetujui**, atau **Ditolak**. Pengajuan yang dibatalkan hanya tampil pada filter **Semua**.
4. Ketuk salah satu pengajuan untuk membuka detailnya.

Arti status:

| Status | Arti |
|---|---|
| **Menunggu** | Belum ditinjau; masih dapat dibatalkan |
| **Disetujui** | Diterima oleh peninjau |
| **Ditolak** | Tidak diterima; baca catatan peninjau |
| **Dibatalkan** | Dibatalkan sendiri oleh pegawai |

[[GAMBAR SS-06-01 | Daftar pengajuan | Tangkapan layar halaman Izin: tombol "Ajukan" di kanan atas, filter Semua/Menunggu/Disetujui/Ditolak, dan daftar pengajuan dengan label status berwarna.]]

## 6.3 Mengajukan Izin

**Tujuan:** memberitahukan ketidakhadiran beserta alasannya.

1. Pada menu **Izin**, ketuk **Ajukan**.
2. Pastikan tab **Izin** terpilih.
3. Pilih **Jenis izin*** (contoh: Sakit, Izin, Cuti, Dinas Luar, Tugas Lapangan; daftar sesuai pengaturan Admin).
4. Isi tanggal **Dari*** dan **Sampai**. Untuk izin satu hari, samakan kedua tanggal.
5. Isi **Alasan***.
6. Lampirkan bukti pada **Lampiran** apabila ada. Untuk jenis izin tertentu (misalnya Dinas Luar) lampiran **wajib** dan kolom diberi tanda *.
7. Ketuk **Kirim pengajuan**.
8. Apabila berhasil, muncul notifikasi **Pengajuan terkirim** dan halaman detail pengajuan terbuka dengan status **Menunggu**.

Ketentuan izin:

- Tanggal boleh hari ini, hari mendatang, maupun hari yang sudah lewat.
- Rentang paling lama **30 hari** dalam satu pengajuan.
- Tidak boleh bertabrakan dengan izin lain yang berstatus Menunggu atau Disetujui.
- Lampiran berupa **JPG, PNG, atau PDF** dengan ukuran paling besar **5 MB**.
- Selama izin berstatus Menunggu atau Disetujui dan pegawai belum absen masuk, Beranda pada tanggal tersebut menampilkan keterangan izin, bukan tombol absen.

[[GAMBAR SS-06-02 | Form izin | Tangkapan layar formulir "Ajukan" tab Izin: pilihan Jenis izin, tanggal Dari dan Sampai, kolom Alasan, kolom Lampiran, dan tombol "Kirim pengajuan".]]

[[GAMBAR SS-06-03 | Lampiran wajib | Tangkapan layar formulir izin dengan jenis "Dinas Luar" terpilih, kolom Lampiran bertanda * dan pesan merah "Lampiran wajib untuk jenis izin ini".]]

## 6.4 Mengajukan Koreksi Absen

**Tujuan:** meminta pencatatan absen masuk atau pulang yang terlewat.

1. Pada menu **Izin**, ketuk **Ajukan**.
2. Pilih tab **Koreksi absen**.
3. Isi **Tanggal*** yang akan dikoreksi (hari ini sampai 7 hari ke belakang).
4. Pilih **Absen*** **Masuk** atau **Pulang**.
5. Isi **Jam*** kehadiran yang sebenarnya.
6. Isi **Alasan*** (contoh: lupa absen, HP mati).
7. Lampirkan bukti bila ada (opsional).
8. Ketuk **Kirim pengajuan**.

Ketentuan koreksi:

- Tanggal paling lama **7 hari ke belakang** dan tidak boleh tanggal mendatang.
- Hanya untuk absen yang **belum tercatat** pada tanggal tersebut.
- Tidak boleh ada pengajuan koreksi yang sama (tanggal dan jenis absen sama) yang masih Menunggu atau sudah Disetujui.
- Koreksi pada hari libur atau hari tanpa jadwal tetap dapat diajukan.
- Setelah **disetujui**, absen otomatis tercatat dan tampil di Riwayat dengan label **Koreksi**. Status keterlambatan dihitung dari jam koreksi dan jadwal kerja.

[[GAMBAR SS-06-04 | Form koreksi absen | Tangkapan layar formulir "Ajukan" tab Koreksi absen: Tanggal (dengan keterangan "Hari ini sampai 7 hari ke belakang"), pilihan Absen Masuk/Pulang, Jam, Alasan, Lampiran, dan tombol "Kirim pengajuan".]]

## 6.5 Apabila Pengajuan Gagal Dikirim

Pesan kesalahan tampil di bawah kolom yang bermasalah atau di atas tombol kirim.

| Pesan | Penyebab dan Penanganan |
|---|---|
| Wajib diisi / Pilih jenis izin | Kolom wajib masih kosong. Lengkapi isian. |
| Tidak boleh sebelum tanggal mulai | Tanggal Sampai lebih awal dari tanggal Dari. Perbaiki tanggal. |
| Rentang izin maksimal 30 hari | Pecah menjadi beberapa pengajuan. |
| Sudah ada izin lain pada rentang tanggal tersebut | Tanggal bertabrakan dengan izin lain. Periksa daftar pengajuan. |
| Lampiran wajib untuk jenis izin ini | Lampirkan bukti. |
| Format harus JPG, PNG, atau PDF / Ukuran maksimal 5 MB | Ganti berkas lampiran. |
| Di luar batas 7 hari | Tanggal koreksi terlalu lama. Hubungi Admin. |
| Absen … pada tanggal tersebut sudah tercatat | Absen tersebut sudah ada; koreksi tidak diperlukan. |
| Sudah ada pengajuan koreksi yang sama | Tunggu hasil peninjauan pengajuan sebelumnya. |

[[GAMBAR SS-06-05 | Pesan gagal kirim | Tangkapan layar formulir dengan kotak pesan merah di atas tombol kirim, contoh "Sudah ada pengajuan koreksi yang sama".]]

## 6.6 Melihat Detail Pengajuan

1. Pada daftar pengajuan, ketuk pengajuan yang dimaksud.
2. Halaman **Detail pengajuan** menampilkan:
   - jenis pengajuan, tanggal (untuk koreksi: tanggal, jenis absen, dan jam), dan status;
   - **Alasan**;
   - waktu **Diajukan**;
   - waktu **Ditinjau** beserta nama peninjau (apabila sudah ditinjau);
   - **Catatan peninjau** (apabila ada, terutama saat ditolak);
   - tombol **Unduh lampiran** (apabila ada lampiran).
3. Ketuk **Unduh lampiran** untuk menyimpan berkas lampiran ke HP.

[[GAMBAR SS-06-06 | Detail pengajuan | Tangkapan layar Detail pengajuan berstatus Ditolak: judul "Izin Sakit", tanggal, label status merah, Alasan, Diajukan, Ditinjau beserta nama peninjau, kotak biru "Catatan peninjau", dan tombol "Unduh lampiran".]]

## 6.7 Membatalkan Pengajuan

Pengajuan hanya dapat dibatalkan selama berstatus **Menunggu**. Pengajuan tidak dapat diubah; apabila ada kesalahan isian, batalkan lalu ajukan ulang.

1. Buka detail pengajuan berstatus **Menunggu**.
2. Ketuk **Batalkan pengajuan**.
3. Pada notifikasi **Batalkan pengajuan ini?**, ketuk **Ya, batalkan** (atau **Tidak** untuk membatalkan).
4. Muncul notifikasi **Pengajuan dibatalkan** dan status berubah menjadi **Dibatalkan**.

Setelah dibatalkan, tanggal yang sama dapat diajukan kembali.

# BAB VIII PENUTUP

## 8.1 Alur Kerja Harian

1. Tiba di kantor → buka Aplikasi ABSEN → **Absen Masuk**.
2. Selesai bekerja → **Absen Pulang**.
3. Tidak dapat masuk kerja → ajukan **Izin** sebelum atau pada hari tersebut, atau sesudahnya apabila mendadak.
4. Lupa atau gagal absen → ajukan **Koreksi absen** paling lambat 7 hari.
5. Pantau status pengajuan di menu **Izin**.

## 8.2 Tanya Jawab

| Pertanyaan | Jawaban |
|---|---|
| Tombol absen tidak muncul. | Periksa keterangan di Beranda: belum jam buka, hari libur, sedang izin, sudah lengkap, atau wajah belum didaftarkan (Subbab 3.2). |
| GPS lama atau "kurang akurat". | Aktifkan mode lokasi akurasi tinggi di HP, keluar ke tempat terbuka, dan tunggu beberapa detik. |
| Muncul "Di luar area" padahal sudah di kantor. | Tunggu GPS lebih akurat lalu ulangi. Apabila tetap gagal, laporkan ke Admin untuk pemeriksaan radius kantor. |
| "Wajah tidak cocok" terus-menerus. | Pastikan cahaya cukup dan wajah menghadap kamera tanpa masker/kacamata gelap. Apabila tetap gagal, minta Admin mendaftarkan ulang foto wajah. |
| Lupa absen masuk. | Absen pulang tetap dapat dilakukan setelah jam pulang; ajukan koreksi untuk absen masuk. |
| Terlewat jam pulang sebelum absen masuk. | Absen masuk sudah ditutup; ajukan koreksi absen masuk. |
| Salah mengisi pengajuan. | Batalkan selama masih Menunggu, lalu ajukan ulang. |
| Pengajuan ditolak. | Baca catatan peninjau pada detail pengajuan, lalu ajukan ulang bila perlu. |
| Jam di HP berbeda dengan aplikasi. | Aplikasi memakai jam server WITA; jam HP tidak berpengaruh. |
| Ganti HP. | Buka alamat aplikasi di HP baru dan login dengan akun yang sama. |
| Lupa kata sandi. | Minta kode pemulihan ke Admin (Subbab 2.4). |

| Istilah | Arti |
|---|---|
